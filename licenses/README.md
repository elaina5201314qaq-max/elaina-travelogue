## 角色、画面与声音

本作是《魔女之旅》的非官方同人作品。伊蕾娜及原作相关设定的权利归相应权利人，项目不宣称拥有这些原作权利。

新增旅途、故事与玩法为本项目创作。人物和场景插画包含 AI 生成及后续调整的素材，并非官方立绘；日文配音为模型合成，并非原作官方声优演出。

Codex 参与程序实现、资源处理与验证，Gemini 参与 UI 设计及部分剧本创作与润色。游戏的创作方式与游玩说明见[项目首页](../README.md)。

本目录中引擎、字体或音效的许可证，不自动适用于游戏内角色、美术、剧情或配音；仓库没有为整个游戏授予统一的开源素材许可。
