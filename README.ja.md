# イレイナの旅の手帖 · 地図にない遠くへ

[简体中文](README.md) | [English](README.en.md) | 日本語

中国語タイトル：**伊蕾娜的旅行手记 · 未标注的远方**

**イレイナが好きな方へ。そして、旅が好きな方へ。**

『魔女の旅々』のイレイナを主人公とした、非公式のファンゲームです。見知らぬ街に立ち寄り、そこで暮らす人たちの話を聞き、旅先の小さな謎を解く。そしてまた箒に乗り、地図にまだ記されていない場所へ向かいます。

気軽なおしゃべりやイレイナの心の中のツッコミもあれば、別れや喪失を描く物語もあります。旅で見聞きすることや彼女の選択を中心に描いており、イレイナが関わる恋愛展開はありません。

**Windows / Android · オフラインで遊べる一人用ゲーム · 日本語の合成音声＋中国語字幕 · 無料でプレイ可能**

この README は日本語の案内です。**ゲーム内の物語字幕は中国語です。日本語の物語字幕や英語字幕を追加するものではありません。** UI は大きな日本語表記に、小さな中国語訳を添えています。

## ゲームの内容

- **6 つの旅と分岐する結末**：さまざまな場所で探索や会話を楽しみ、選択を重ねながら、旅先の小さな発見を集めます。
- **長編サイドストーリー『未干的红伞与扫轨人』**：同じ街で過ごす時間と、その後の再訪を通じて、旅先で出会う人々を知っていく物語です。読了した章は読み返せます。
- **日本語と中国語による表示**：UI は日本語の大きな文字と中国語の小さな訳を併記。物語には日本語の合成音声と中国語字幕が付きます。
- **旅先のミニゲーム**：箒での飛行、天気の調整、星図のパズル。場面や会話には小さなおまけも隠れています。
- **着せ替えと記念撮影**：解放した衣装、ポーズ、表情を切り替え、お気に入りの景色と一緒に写真を残せます。
- **5 本のストーリー CG**：物語の進行に合わせて解放され、あとから再生、一時停止、スキップができます。イラストにカメラワーク、部分的な動き、背景のアニメーションを組み合わせて制作しています。
- **オートセーブ**：進行状況のエクスポートとインポートに対応。同じ形式のセーブデータは Windows 版と Android 版の間で移行できます。

## インストールと起動

### Windows

1. `ElainaTravel-Windows-1.3.0.zip` をダウンロードします。
2. ZIP の内容をすべて、任意のフォルダーに展開します。
3. 中にある `伊蕾娜的旅行手记.exe` を起動し、旅を始めます。

ZIP の中から直接実行せず、先に展開してください。同梱の説明書とライセンスファイルも保管してください。現在の EXE はコード署名を行っていません。発行元不明の表示が出た場合は、ダウンロード元とチェックサムを確認してください。セキュリティ機能を無効にする必要はありません。

### Android

1. スマートフォンに `ElainaTravel-Android-1.3.1.apk` をダウンロードします。
2. ファイル管理アプリから APK を開きます。インストール権限を求められた場合は、使用中のファイル管理アプリに限って「不明なアプリのインストール」を許可します。
3. インストール後、端末を横向きにして遊んでください。インストール権限は、作業後に無効に戻せます。

現在のバージョンは Android 11 エミュレーターで、インストール、タッチ操作、セーブ、音声、CG を確認しています。**実機の Android スマートフォンでは未検証です。** 動作上の問題があれば、機種名と Android のバージョンを添えてご報告ください。

現在は Windows 版と Android 版のみ配布しています。iOS、macOS、Linux 向けのインストールファイルはありません。

## 操作方法

### Windows：キーボードとマウス

| 操作 | キー |
| --- | --- |
| 物語を進める | `Space` / `Enter` |
| 選択肢を選ぶ | 数字キー、またはマウスでクリック |
| 自動再生の切り替え | `A` |
| UI の表示 / 非表示 | `H` |
| 全画面表示の切り替え | `F11` |
| 戻る | `Esc` |
| CG の一時停止 / 再開 | `Space` |
| CG をスキップ | `Esc` |
| 飛行中の高度調整 | `↑` / `↓`、`W` / `S`、またはマウスを押したまま航路を調整 |

### Android：タッチ操作

- 「继续」をタップすると会話が進みます。文章や選択肢が長い場合は、その表示領域を上下にスクロールできます。
- 「看风景」で UI を隠し、画面をタップすると再表示できます。
- 飛行中は画面を押したまま上下にドラッグして高度を調整します。
- 撮影画面では人物をドラッグして配置し、解放した衣装・表情・ポーズを切り替えられます。
- 端末の戻る操作でダイアログを閉じたり、前の画面に戻ったりできます。

音量、文字表示、自動読み進め、CG の自動再生などは **「旅の鞄 / 行李箱」** で調整できます。

## セーブデータと写真

進行状況は自動で保存されます。Windows の保存先は `%APPDATA%\ElainaTravel`、Android ではアプリ専用の保存領域です。

**Android 版をアンインストールする前、アプリのデータを消去する前、機種変更の前には、セーブデータをアプリの外に書き出してください。** アプリ内のバックアップも、アンインストールやデータ消去で一緒に失われます。現在の Android 版では OS の自動バックアップを有効にしていません。

書き出すには「行李箱 → 导出存档」を開きます。Android では「复制存档文字」で全文をコピーし、アプリ以外の場所に保存してください。読み込むには「行李箱 → 导入存档」で全文を貼り付け、検証を行い、現在の進行状況を置き換えることを確認します。同じ形式のセーブテキストを使って、Windows と Android の間で進行状況を移せます。

書き出されるのは進行状況と設定です。**撮影した写真は含まれません。** Android の写真はゲーム内のアルバムに保存され、端末の写真アプリには自動保存されません。
